# TCG Decklists Backend

Java 21 Spring Boot application initialised using
[Spring Initializr](https://start.spring.io/).

Selecting the following options in the initializr:

1. `Gradle - Kotlin` for the project
2. `Java` for the language
3. `3.5.6` for the Spring Boot language
4. `Jar` for the packaging
5. `21` for the Java version
6. Added the following dependencies
   1. Spring Web
   2. Spring Data JPA
   3. Liquibase Migration
